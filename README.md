# Node Command — Host Control for AI Agents

Node Command lets AI assistants (ChatGPT, Claude, OpenCode, Cursor, VS Code) securely
operate your computers: run shell commands, manage files, read logs, automate
browsers — through one Model Context Protocol (MCP) endpoint.

- **Agent:** open source endpoint runtime → [`nc-agent`](https://github.com/huseyincig/nc-agent)
- **Protocol:** open wire + MCP contracts → [`nc-protocol`](https://github.com/huseyincig/nc-protocol)
- Start: `docs/getting-started.md`
